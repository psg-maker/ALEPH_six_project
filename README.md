# ALEPH — 내 계획과 실제를 담는 앱

FastAPI · SQLAlchemy · SQLite로 만든 Plan → Do → See 기록 앱입니다. 화면과 API는 같은 FastAPI 서버에서 제공합니다. 로그인은 없으며, 공개 배포하면 링크를 아는 사람이 자료를 조회·변경할 수 있습니다.

## 실행 — Windows Git Bash

현재 개발 환경은 Python 3.13입니다. 프로젝트 루트에서 실행합니다.

```bash
# 가상환경이 없을 때만 생성
python -m venv venv

./venv/Scripts/python.exe -m pip install -r requirements.txt
./venv/Scripts/python.exe -m uvicorn app.main:app --reload
```

- 앱: http://127.0.0.1:8000/
- API 확인: http://127.0.0.1:8000/docs
- 종료: `Ctrl+C`

8000 포트를 사용할 수 없다면 기존 서버를 종료하거나 `--port 8001`을 붙이고 접속 주소도 8001로 바꿉니다. HTML 파일을 직접 열거나 Live Server로 실행하지 않습니다.

Linux에서는 별도로 만든 가상환경의 `./venv/bin/python`을 사용합니다. Windows 가상환경을 복사해 사용하지 않습니다.

## 데이터 보관

`planner.db`는 **서버를 실행한 현재 폴더**에 생성됩니다. 항상 프로젝트 루트에서 실행하세요. 다른 폴더에서 실행하면 다른 DB가 생길 수 있습니다. 기존 DB는 삭제하거나 초기화하지 않습니다.

- 소스만 clone하면 개인 데이터가 자동 복원되지 않습니다. DB·백업·환경변수는 Git에서 제외합니다.
- 실행 중인 앱을 종료한 뒤 DB를 별도 위치에 복사해 백업합니다. `전체 기록 내보내기`는 7개 테이블의 JSON을 다운로드하지만 현재 JSON 가져오기 기능은 없습니다.
- 새 DB는 서버 시작 시 테이블이 생성됩니다. 기존 DB의 컬럼 변경은 자동 적용되지 않습니다.
- 오래된 DB에서 `executions.blocked_reason`이 없다는 오류가 나면 삭제 대신 백업 후 스키마를 확인해야 합니다. 필요한 변경은 `ALTER TABLE executions ADD COLUMN blocked_reason TEXT`이며, 이미 컬럼이 있는 DB에 다시 실행하지 않습니다.

테이블·컬럼·외래키·NULL·고유 조건과 동작 규칙은 [DB 계약](contracts/pds-schema-v2.json)에 기록했습니다. 이 파일은 현재 구현의 명세이며 DB 마이그레이션을 실행하는 파일은 아닙니다.

## 사용 및 확인 — 세 단계

1. `새 계획`을 만든 뒤 연결된 할 일을 추가합니다. 계획은 수정 후 `수정 이력`에서 이전 내용을 확인할 수 있습니다.
2. 할 일의 `실행 기록`에서 실제 시간을 분 단위로 직접 입력하고 완료를 체크합니다. 예상 시간과 실제 시간은 별도로 저장되며 스톱워치는 없습니다.
3. `돌아보기`에서 계획을 선택하고 집계 숫자를 눌러 근거를 확인합니다. 회고의 고칠 점을 저장한 뒤 다음 계획에 반영할 수 있습니다.

통과 확인: 새로고침과 서버 재시작 뒤 자료가 남고, 집계와 근거 기록이 일치하며, 반복 완료로 실행 기록이 추가되지 않습니다. 날짜별 메모도 저장할 수 있습니다. 저장 전 메모 초안은 현재 페이지 안에서만 유지됩니다.

안 될 때: 서버 실행 로그와 접속 포트를 확인합니다. 목록 조회 오류는 화면의 재시도를 사용하고, DB 컬럼 오류는 위 데이터 보관 항목을 확인합니다. 같은 값은 화면에서 ID 오름차순으로 정렬하며 미입력은 항상 마지막입니다.

## 휴대폰 확인

PC와 휴대폰을 같은 Wi-Fi에 연결합니다.

```bash
./venv/Scripts/python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

다른 터미널에서 `ipconfig`로 사용 중인 네트워크의 IPv4 주소를 확인하고 휴대폰에서 `http://PC의IPv4주소:8000/`을 엽니다. 신뢰하는 사설 네트워크의 방화벽 허용이 필요할 수 있습니다. 이 주소는 제출용 공개 주소가 아닙니다. 확인 후 서버를 종료합니다.

## 테스트

개인 DB와 분리한 메모리 DB를 사용합니다.

```bash
./venv/Scripts/python.exe -B -m unittest discover -s tests -v
node --check app/static/planner.js
```

DOM/API 연동 테스트는 [테스트 설명](tests/README.md)을 따릅니다. DOM 테스트는 실제 브라우저 배치·키보드·휴대폰 조작을 대신하지 않습니다.

## 배포 및 제출 상태

공개 앱 배포는 아직 완료되지 않았습니다. GitHub Pages는 Python 서버를 실행하지 않으므로 이 앱 전체를 동작시키는 배포 환경이 아닙니다. FastAPI 실행 환경과 영구 DB 저장 공간이 필요합니다.

현재 날짜와 생성 시각은 서버 로컬 시간 기준이며 명시적인 한국 시간 변환은 없습니다. 실행 시각은 시간대 없는 입력값을 그대로 저장합니다. 배포 전에 DB 경로·영구 저장소와 시간대 정책을 확정해야 합니다.

현재 돌아보기는 선택한 계획의 전체 기록 기준입니다. 임의 날짜 범위 집계는 없습니다. 최종 공개 URL, 고정 commit URL, 공개 가능한 실제 기록과 AI 활용 총평 등은 [제출 점검표](SUBMISSION_CHECKLIST.md)에서 관리합니다. 채팅 버전의 빈 제목 자동 생성은 후속 계획이며 현재 기능이 아닙니다.
